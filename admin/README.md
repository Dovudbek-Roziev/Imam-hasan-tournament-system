# Веб-панель администратора

Адаптивная панель управления турниром: обзор показателей, команды, игроки, расписание и протокол матчей, новости. Интерфейс переключается между русским и кыргызским языками; даты и время показываются для Оша (Asia/Bishkek, UTC+6).

## Локальный запуск

1. Установите зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env`. Для локальной разработки `VITE_API_URL` задавать не нужно: запросы `/api` проксируются на `http://127.0.0.1:5000`. Если backend работает на другом адресе, укажите `API_PROXY_TARGET`.
3. Запустите backend и подключите MongoDB согласно [руководству backend](../backend/README.md). Для входа в админку создайте учётную запись командой `npm run admin:create` из каталога `backend`.
4. Запустите панель: `npm run dev` и откройте адрес Vite, показанный в терминале.

Сборка production-ресурсов: `npm run build`. Предварительный просмотр сборки: `npm run preview`.

## Возможности

- Вход администратора, проверка роли, продление проверки сессии и серверный выход.
- Создание, поиск, редактирование и удаление команд, игроков, матчей и новостей.
- Протокол матча: голы, автоголы, карточки и ассисты; API проверяет состав участников и согласованность итогового счёта.
- Статистика турнира и скачивание JSON-архива истории.
- Страницы списка используют серверную пагинацию и фильтры API.
- Логотип команды можно выбрать с компьютера или из галереи телефона: JPEG, PNG и WebP размером до 2 МБ.

Токен хранится только в `sessionStorage` текущей вкладки и автоматически добавляется к запросам API. Не помещайте секреты в переменные `VITE_*`: они доступны браузерной сборке.
