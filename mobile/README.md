# Мобильное приложение турнира

Приложение для зрителей на Expo SDK 57: главная страница с ближайшей игрой и новостями, таблица, календарь матчей, рейтинг голов/ассистов и карточек. Интерфейс переключается между русским и кыргызским языками; расписание отображается по часовому поясу Оша (Asia/Bishkek, UTC+6).

## Запуск

Используется Expo SDK 57 и React Native 0.86. Для этой версии Expo требует Node.js 22.13 или новее; совместимость SDK указана в [официальной документации](https://docs.expo.dev/versions/v57.0.0/).

```powershell
cd mobile
npm ci
Copy-Item .env.example .env
```

В обычном режиме Expo Go адрес компьютера, на котором работает Metro, определяется автоматически; задавать `.env` для локального запуска не нужно. Backend должен быть запущен на порту `5000`, а телефон и компьютер должны находиться в одной доступной сети. При использовании Expo Tunnel укажите доступный телефону адрес backend вручную через `EXPO_PUBLIC_API_URL`.

Для production/EAS приложение по умолчанию использует API турнира на Render. При переносе backend задайте `EXPO_PUBLIC_API_URL` с новым публичным адресом, например `https://api.example.com/api`. На физическом телефоне `localhost` указывает на сам телефон, поэтому для ручной локальной настройки используйте LAN-IP компьютера.

```powershell
npx expo start
```

Откройте QR-код в Expo Go или запустите симулятор. Для iOS/Android production-сборки потребуется отдельно задать app identifiers, ресурсы бренда и credentials в EAS.

## Данные и поведение

- Вход в мобильном приложении не требуется: оно предназначено для зрителей и показывает данные турнира в четырёх вкладках.
- Если экран пуст, сначала запустите backend с подключённой базой и добавьте команды, игроков, матчи и новости через веб-панель администратора.
- Главная запрашивает ближайшие запланированные матчи и последние новости; таймер обновляется локально на устройстве.
- Таблица, расписание, топ бомбардиров и ассистентов получают публичные данные backend API.
- Рейтинг карточек рассчитывается из публичного списка игроков и показывает жёлтые/красные карточки.
- Из календаря открывается протокол матча, из таблицы — состав команды и её показатели.
- На всех экранах есть pull-to-refresh, локализованное сообщение об ошибке и повторная загрузка. Язык ошибок API передаётся заголовком `Accept-Language`.
- Мобильное приложение только читает API; права администратора и изменение данных остаются в веб-панели.

Локальная проверка JS bundle: `npx expo export --platform android --output-dir .expo/export`. Для надёжной работы инструментов Expo используйте Node.js 22.13+; SDK 57 ещё не проверялся на физических Android/iOS устройствах.

## Карточка разработчика / Иштеп чыгуучунун карточкасы

Карточка разработчика расположена на главном экране сразу после ближайшего матча, перед новостями. Здесь можно изменить имя, специализацию, перечень услуг и текст предложения. Единственная кнопка связи открывает Instagram `@dovudbek.roz1ev`. После изменения любого текста добавьте его кыргызский перевод в `src/i18n/index.js`.

Карточка намеренно стоит после ближайшего матча: её видно на главной, и она не перекрывает турнирную информацию. Перед публикацией приложения получите согласие организатора турнира на размещение рекламы.

Иштеп чыгуучунун карточкасы башкы бетте жакынкы беттештен кийин, жаңылыктардын алдында турат. Атын, адистигин, кызматтарын жана сунуш текстин `src/screens/HomeScreen.js` файлынан өзгөртүңүз. Байланыш баскычы Instagram `@dovudbek.roz1ev` барагын ачат. Текстти өзгөрткөндөн кийин анын кыргызча котормосун `src/i18n/index.js` файлына кошуңуз.

Карточка көбүрөөк көрүнсүн десеңиз, анын JSX бөлүгүн жакынкы беттештин маалыматынын астына жылдырсаңыз болот. Аны беттештин үстүнө калкып чыгуучу жарнама кылбаңыз: портфолио жана байланыш баскычы бар чакан карточка көрүүчүлөргө тоскоол болбойт. Колдонмону жарыялоодон мурун турнир уюштуруучусунан жарнаманы жайгаштырууга уруксат алыңыз.
